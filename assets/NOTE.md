# README screenshots

The top-level `README.md` references three images from this folder. Save the
dashboard screenshots here with these **exact filenames** so the links render on
GitHub:

| Filename | Screenshot |
|---|---|
| `overview.png` | Overview page — full dashboard (simulation control, electricity price, demand pattern, network diagram, tanks, pumps). |
| `energy-network-info.png` | The Energy + Network Info panels (per-step power/energy/cost and static topology stats). |
| `prediction-engine.png` | Prediction Engine page — per-node pressure chart plus SHAP feature importance. |

PNG is preferred. Once the files are here, run:

```bash
git add assets/*.png
git commit -m "docs: add README screenshots"
git push
```
